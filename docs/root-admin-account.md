# root 관리자 계정

| 항목 | 설명 |
|------|------|
| 계정 이름 | `root`는 Linux의 관리자 계정이다. 계정 ID는 `0`이며, 일반 사용자보다 많은 시스템 변경 권한을 가진다. |
| 할 수 있는 작업 | 컨테이너 안에서 패키지를 설치하거나 시스템 파일을 변경·삭제할 수 있다. 따라서 명령을 입력할 때 대상이 컨테이너 안인지 확인한다. |
| 권한의 범위 | 여기서의 `root`는 현재 Ubuntu 컨테이너 안의 계정이다. Windows 관리자 계정이나 WSL Ubuntu의 `userk` 계정을 뜻하지 않는다. |
| 이번 실습에서 root인 이유 | `docker run -it ubuntu bash`에서 다른 계정을 지정하지 않았고, Ubuntu 이미지가 기본으로 `root` 셸을 시작했다. |
| 일반 사용자와 차이 | 일반 사용자는 시스템 전체를 바꾸는 권한이 제한된다. 필요하면 관리자 권한으로 허용된 작업만 수행한다. |

프롬프트 `root@2adb9b993bcc:/#`에서 `root`는 관리자 계정, `2adb9b993bcc`는 컨테이너를 가리키는 호스트 이름, `/`는 현재 폴더다. 끝의 `#`는 root 셸 표시이며, 일반 사용자 셸은 보통 `$`로 끝난다.

컨테이너 이름을 지정하지 않으면 Docker가 이름을 자동으로 붙인다. 이름을 직접 정할 때는 명령에 `--name`을 추가한다. 예: <span style="color: #0969da;"><code>docker run -it --name my-ubuntu ubuntu bash</code></span>.
